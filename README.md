# NexAI Software - Landings Portfolio

Public collection of landing pages and static sites created for product, personal brand and client-facing projects.

This repository is meant to show visual frontend work, product positioning, responsive static sites and deployment-ready landing pages.

## Projects

| Folder | Project | Focus |
| --- | --- | --- |
| `fernecito-landing/` | Fernecito App | Product landing for an events, nightlife, squads and reservations platform. |
| `santiago-medrano-portfolio/` | Santiago Medrano Portfolio | Personal portfolio for product engineering, UX and fullstack development. |
| `luli-cutes-3d/` | Luli Cute's 3D | Commercial landing for cute/kawaii 3D printed products. |
| `nm-mkt/` | NM.MKT | Static website for a digital marketing, branding, production and web agency. |

## What This Shows

- Responsive landing page implementation.
- Visual storytelling and product positioning.
- Static frontend structure with real assets.
- Different styles for different audiences: SaaS/product, personal brand, retail and agency.
- Production-friendly organization without private deploy metadata.

## Safety Notes

This is a public portfolio repository.

It intentionally excludes:

- `.env` files and environment-specific secrets.
- Vercel project metadata.
- Local build outputs.
- Zipped backups and unrelated local files.
